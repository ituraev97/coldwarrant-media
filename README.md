# COLD WARRANT — media & pipeline

- `pipeline/` — production scripts (graphics, narration, edit, mix, encode, Shorts, thumbnails).
- `episodes/` — episode scripts (`episode.py`), sources and thumbnail configs. No video files on `main`.
- `drop-mon` … `drop-sun` branches — rotating upload slots: each holds only one day's video files (force-pushed daily) so Metricool can fetch them by public raw URL.
- `RUNBOOK.md` — step-by-step for the daily automated run. `backlog.md` — upcoming cases.
